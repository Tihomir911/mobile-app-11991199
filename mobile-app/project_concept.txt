1. Назначение приложения

Разработка простого, но функционального мобильного приложения для ведения текстовых заметок с системой авторизации пользователей. Приложение предназначено для использования в учебных целях и демонстрирует базовые навыки работы с интерфейсом, базами данных и файловой системой на платформе Android.

2. Основной функционал (GUI)

2.1. Экран входа (авторизация)
- На главном экране присутствует кнопка «Вход» (Login).
- При нажатии на неё пользователю открываются два текстовых поля для ввода логина и пароля.
- После ввода учётных данных выполняется запрос к локальной базе данных SQLite.
- Если пользователь с такими данными найден — выполняется успешный вход в приложение.
- Если пользователь не найден — его учётная запись автоматически создаётся в базе данных как новая.

2.2. Главный рабочий экран (Текстовый редактор)
- После успешной авторизации открывается основной экран с простым текстовым редактором.
- Пользователь может вводить и редактировать любой текст в этом поле.

2.3. Управление данными и файлами
- Кнопка «Сохранить» (Save): при нажатии текущий текст из редактора сохраняется во внутреннюю базу данных SQLite (привязывается к текущему пользователю).
- Кнопка «Выбрать файл» (Select file): открывает интерфейс выбора существующего файла для записи в него текста из редактора.
- Кнопка «+» (Плюс): находится в том же интерфейсе выбора файла. Позволяет пользователю создать новый текстовый файл, указав его название вручную.

2.4. Выход из системы
- Кнопка «Выйти» (Logout): при нажатии пользователь мгновенно разлогинивается (сессия завершается), и приложение возвращается на начальный экран входа с последующим закрытием приложения.

3. Технологический стек
- Среда разработки: Android Studio (последняя стабильная версия).
- Язык программирования: Kotlin (допускается использование Java или python c++).
- База данных: SQLite (встроенная в Android) — используется для хранения учётных записей пользователей и сохранённых заметок.
- Хранение файлов: внутренняя память устройства (папка приложения).

4. Особенности реализации
- Приложение полностью автономно и не требует подключения к интернету.
- База данных и файлы хранятся локально на устройстве пользователя.
- Интерфейс минималистичный, интуитивно понятный и ориентирован на быстрое выполнение основных сценариев (запись — сохранение — выход).

5. Целевая аудитория
- Студенты колледжа, преподаватели, а также любые пользователи, которым требуется быстрое и безопасное приложение для ведения личных заметок с возможностью сохранения в отдельные файлы.
